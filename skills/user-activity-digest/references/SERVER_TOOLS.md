# JSONPlaceholder Server Tools

Tools used by this skill from `@nimblebraininc/jsonplaceholder`:

- `get_user(user_id)` — Get a single user by ID (1-10)
- `list_posts(user_id?)` — List posts, filter by user ID
- `get_user_todos(user_id)` — Get all todos for a specific user
- `get_post_comments(post_id)` — Get all comments for a specific post
